# Nested Modeling of the Hudson River Estuary and New York Bight

This subproject develops a high-resolution nested ROMS model for the
Hudson River estuary and New York Bight as part of the ECCOFS-SAB
nesting, downscaling, and coupling project.

The model will use the ECCOFS product as the larger-scale parent
solution and develop a higher-resolution child model for the
Hudson River estuary and adjacent New York Bight.

## Objectives

- Develop the high-resolution nested model domain.
- Downscale the parent ECCOFS solution to the study region.
- Develop and test the necessary grid, boundary, initial, and forcing files.
- Evaluate the nested model performance against the parent ECCOFS solution and available observations.
- Investigate estuarine and shelf-scale circulation and exchange processes.

## Study Region

Hudson River estuary and New York Bight.
